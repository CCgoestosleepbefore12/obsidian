## 核心思想 / 为什么这样做

示范 / 参考运动（人类动捕、专家轨迹、网络视频）在 RL 里能扮演**两种角色**，这是一对反复出现的根本张力：

| | **硬跟踪约束**（hard constraint） | **软塑形先验**（shaping prior） |
| :--- | :--- | :--- |
| 参考的作用 | 部署时必须逐帧/逐步跟住的目标轨迹 | 训练时塑形行为的先验，**部署时丢掉** |
| 动作自然度 | 高（直接复制） | 高（被先验塑形） |
| 泛化能力 | **差**——出了示范分布就垮 | **好**——能 steer 到新目标 / 新环境 |
| 典型失败 | 脆、无法适应新条件 | 若先验太弱 → 退化；太强 → 锁死 |
| 怎么实现 | tracking reward / phase 变量 / 参考当输入 | 多任务联合（模仿 + 任务）、对抗分布匹配、advantage 当条件…… |

**为什么"软先验"更值钱**：纯任务驱动 RL 能泛化但动作退化（趴地爬、抽搐、利用仿真器 bug）；纯硬跟踪动作好但脆。软先验想两头都要——用参考**注入**协调自然的运动结构，同时保留**偏离参考去完成新任务**的自由度。

**实现"软先验"的几条技术路线**（各实例的差异就在这）：
1. **多任务联合 + 共享观测**：模仿任务塑形技能、任务/泛化任务学迁移，共享一套 goal-conditioned 观测，推理时不喂参考。（HIL / Multi-Task Ref RL）
2. **对抗分布匹配**：判别器奖励"像示范分布"而非"跟住某条轨迹"，比逐帧跟踪灵活。（AMP / ASE）
3. **advantage 当条件**：不最大化奖励，把"改进量"离散化当 token 喂给原策略，推理时 prompt「最大改进」。（RECAP / RISE，详见 [[Advantage-conditioned 微调]]）

> [!tip] 判定测试（这概念是不是"软先验"）
> 部署/推理时还需要参考运动吗？**需要 = 偏硬约束；不需要 = 软先验。**

## 对立思路

- **纯硬跟踪（motion tracking）**：动作最自然但**不可 steer**、出分布即垮。蒸馏流派（MaskedMimic）虽加了 masking/distillation，本质仍在 tracking 设定内，对新交互泛化差。
- **纯任务驱动 RL（no reference）**：能泛化但**动作退化**，且利用仿真器缺陷。
- **对抗目标本身的取舍**：AMP/ASE 灵活，但动态/接触丰富场景判别器难稳、易 collapse；**真机上尤其难调**——Multi-Task Ref RL 正是因此在 sim→real 时**主动砍掉对抗目标**，改用"模仿 tracking reward 当软正则 + 物理 assistive 课程"。这条"sim 能用对抗、real 退回 dense reward"的经验值得记。
