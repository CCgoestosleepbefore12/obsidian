## 1. 顶层：RL 后训练的统一式（作用域只到 RL 这个圈）

所有"用 RL 改进一个预训练策略"的方法，都在逼近**同一个目标策略**：

$$\pi_{+}(a\mid s)\ \propto\ \pi_{\text{ref}}(a\mid s)\cdot \exp\!\big(A(s,a)/\beta\big)$$

PPO / DPO / RECAP / DSRL / CFGRL / 我的 v_target 全是它的近似。区别只在填**三个自由度**：

| 自由度 | 是什么 | 取值（库里例子） | 对应已有框架 |
| :--- | :--- | :--- | :--- |
| **① A 从哪来** | 价值/优势/偏好信号来源 | 稀疏reward · critic · 人类偏好 · progress-VLM · *世界模型想象（→邻居）* | 主题地图 §4 信号来源轴 |
| **② 在哪个口子注入** | `exp(A/β)` 怎么作用到 π_ref | 输出重排① · 噪声② · 梯度③ab · 偏好③c · 条件④ · **速度场★** | [[Diffusion-Flow 策略的 RL 改进路线图]] 4 口子 |
| **③ β 多狠** | 往最优推多硬 | 固定 β=1(RECAP) · 可调 w([[Advantage-conditioned 微调#理论基石：CFGRL\|CFGRL]]) · KL 系数(PPO) | CFGRL 节 |

> [!warning] 作用域：这行公式**只管 RL 圈**，不吞邻居
> 三自由度全是 RL 圈内部的事。**世界模型 / 推理动力学是两个独立 topic**，只在交集点接触 RL，不是 RL 的子维度：

```
   [世界模型 主题]                          [推理动力学 主题]
   表示学习·视频预测·                        chunking·异步执行·
   规划(MPC,完全无RL)                        delta-action·token生成
         │                                         │
         │ 交集:想象=价值来源                       │ 交集:chunk级/异步
         │  (只喂进 DOF①)                          │ 信用分配(只擦一下②)
         ▼                                         ▼
   ┌──────────────────────────────────────────────────────┐
   │           RL 后训练 主题  ← 统一式只管这个圈            │
   │   π+ ∝ π_ref · exp(A/β)                               │
   │   三自由度全在圈内: A来源 · 注入口子 · β强度            │
   │   ★ 我的 v_target 在这里面                            │
   └──────────────────────────────────────────────────────┘
```

- 世界模型 ∩ RL = 「想象当价值来源」，**喂进** DOF①——但世界模型远不止这块，详见 [[世界模型 主题地图]]。
- 推理动力学 ∩ RL = 「chunk 级 / 异步信用分配」，**擦一下**注入口子——但它和 RL 正交，详见 [[推理动力学 主题地图]]。
  - 我的 bet 实际从这个邻居**借了一把刀**：[[Legato 速度场推导]] 的"反解成 v_target"范式（Legato 本身是 RTC chunk 衔接，**纯推理动力学、非 RL**）。借的是方法论，不是把 Legato 算进 RL。
- 三个 topic **平级，只在边界握手**。

## 2. 中层：价值注入的 2D 定位图

> 把统一式的 **②注入口子** × **A 的保真度** 投影成 2D（DOF① 来源固定、DOF③ β 暂不画）。

```
   信息量高(连续·稠密·保幅度)
            ↑
            │                          ★ 我的 v_target
   QAM/FQL ③b ●                       (连续advantage写进速度场)
   (Q绕链,稠密)        ● RECAP/RISE ④      ← 右上角现在是空的
            │         (advantage离散bin条件)
  ①②外部 ───┼─────────────────────────── 内化·改训练目标
   V-GPS ● ● DSRL                ● DPPO/π_RL ③a
   (重排)  (噪声critic)            (scalar reward穿链PG)
            │                   ● RPRO/FlowPRO ③c
            │                   (二元偏好,丢幅度)
            ↓
   信息量低(二元·稀疏)
```

- **横轴 = 价值信号住哪里**（外部黑盒 → 写进速度场）：给**工程**看——越左越便宜安全、越不碰预训练；越右天花板越高但越贵越不稳。
- **纵轴 = 信号信息量/保真度**（二元稀疏 → 连续保幅度）：给**学术**看——就是"保不保 advantage 幅度"这条命门。
- **右上空角 = 内化 × 高保真 = 机会**：把最丰富的信号用最内化的方式注入，现在只有我。QAM 在它下方（Q 梯度，非 advantage 加权）、RECAP 在它左下（离散、半内化、被稀释）。

## 3. 底层：我的 bet

**一句话**：把 chunk 级 advantage 的**连续幅度加权，原生写进 flow 的速度场目标 v_target**——既内化、又不被稀释、又保幅度。

> 方法论是从推理动力学侧借的（[[Legato 速度场推导]] 的"反解成 v_target"范式，**Legato 非 RL**）；把它用到 RL 的 advantage 注入上、那套 v_target 推导**是我自己的活**。

**三元组定位**：

| 自由度 | 我的选择 |
| :--- | :--- |
| ① A 来源 | critic / 世界模型 value（chunk 级 advantage） |
| ② 注入口子 | **速度场 v_target（最内化）** |
| ③ β | 连续幅度加权（保幅度，不离散化、不二元化） |

### 动机（从工程倒推，这是我比纯学术强的支点）

真实部署里**不能大改预训练 VLA**（成本/稳定/泛化保留），但又要它在真实任务上变强。现有四条口子都不够用：

- ①② 把 base 当黑盒 → 天花板低
- ③a 穿去噪链 → 不稳、贵
- ④ advantage 当 conditioning token → **被 VLM 上下文稀释**（FlowPRO 实测）
- ③c 二元偏好 → **丢掉 advantage 幅度**

→ 把**连续保幅度的 advantage 直接写进速度场**：内化（不靠外挂）+ 不稀释（不走 token）+ 保幅度（不退化成二元）。工程约束 → 学术贡献的支点。

### 必打的两个 baseline

| baseline | 口子 | 软肋（我从哪包抄） | arXiv |
| :--- | :--- | :--- | :--- |
| **π0.6\* / RECAP** | ④ 条件 | advantage token 被上下文稀释 | [2511.14759](https://arxiv.org/abs/2511.14759) |
| **RPRO / FlowPRO** | ③c 偏好 | 二元偏好丢 advantage 幅度 | [2606.14409](https://arxiv.org/abs/2606.14409) |

→ 我正好从它们各自缺的那条轴**上方**包抄（保幅度 + 不稀释）。

### 关键路径读序（学术层深读队列）

1. **DSRL**（在读，[2506.15799](https://arxiv.org/abs/2506.15799)）— 噪声空间标杆 + 那条 RISE 矛盾证据
2. **DPPO**（[2409.00588](https://arxiv.org/abs/2409.00588)）— 穿链 PG 奠基，两边都拿它当 baseline
3. **FQL**（[2502.02538](https://arxiv.org/abs/2502.02538)）— QAM 前置
4. **QAM**（[2601.14234](https://arxiv.org/abs/2601.14234)）— critic 梯度→逐步监督，离我最近的"③b 内化"
5. ③c 补 **Flow-DPO**（RPRO 前身，arXiv 待核实）
6. 理论母体 **CFGRL**（[2505.23458](https://arxiv.org/abs/2505.23458)）— 已在 [[Advantage-conditioned 微调]] 摘过
